Wie Rootwise in Home Assistant sitzt

PLAN v1 · Stand 27.09.2026
Eine Pflanze = ein Subentry + ein DeviceStruktur im Config Entry, alles Wechselnde in 2 Stores. Ändert sich die Struktur, lädt der Entry neu.
Ungefähr 14 Recorder-Zeilen pro Pflanze und TagKein state_class auf abgeleiteten Werten, statische Attribute, Write-Guard. Schont die SD-Karte.
Lokal später nachrüstbarOllama auf dem Gaming-PC wird einfach eine zweite AI-Task-Entity. Kein eigener KI-Client nötig.
